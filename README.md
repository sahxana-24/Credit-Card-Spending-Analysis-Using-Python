Credit Card Spending Analysis Using Python

Project Overview

This project analyzes a simulated credit card transaction dataset to understand customer spending behavior and generate meaningful business insights. The project follows a complete data analytics workflow, including data cleaning, feature engineering, exploratory data analysis (EDA), data visualization, and business recommendations.

Business Objective

The objective of this project is to help a bank understand customer spending patterns by analyzing transaction data. The analysis focuses on identifying spending trends, customer preferences, and business opportunities that can support data-driven decision-making.

Tools and Technologies

• Python
• Pandas
• NumPy
• Matplotlib
• Microsoft Excel
• Google Colab

Dataset Information

The dataset contains simulated credit card transaction records with customer demographics, transaction details, payment methods, merchant categories, cities, card types, and transaction amounts.
